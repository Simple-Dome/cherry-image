# 待测试

- 无限画布视频任务：提交接口返回 `task_id` 后，视频节点立即显示远端状态、任务 ID、进度和“立即查询”；客户端停止、刷新、轮询超时或网络中断后仍可继续查询。远端状态完成时统一显示 100%，并通过“下载视频”单独调用 `/content` 取回视频，不会在普通进度查询时下载大文件。
- 视频参考素材规则：video-v1-10s、video-v1-5s、video-v1-15s 按参数 900 处理，最多 9 张图片且以 Base64 发送，会拒绝视频/音频参考；as-sd2.0-fast、video-ds-2.0-fast、video-ds-2.0 按参数 431 处理，最多 4 张图片、3 个视频、1 个音频，全部素材会转为公网 URL 后发送。
- 画布素材 URL：粘贴素材 URL 现在支持图片直链，会按图片比例创建图片节点；原视频和音频直链能力保持不变。
- Codex App 插件文档：新增插件安装教程，区分 AI 自动安装、手动安装和本仓库开发调试安装；同步优化插件 README 与技能说明。
- 配置与用户偏好：每个模型渠道新增 OpenAI / Gemini 调用格式选择，默认 OpenAI，切换默认格式时同步更新默认 Base URL；渠道 Tab 增加紧凑醒目的提醒，说明模型是否可选需要到“模型”Tab 选择。
- Gemini 调用格式：支持拉取 Gemini 模型列表，并用于文本问答、在线 Agent 工具调用、基础生图和图生图请求。
- 音频和视频生成：选择 Gemini 调用格式时先给出不支持提示，仍需使用 OpenAI 兼容渠道。
